Supported formats and limits

  • Input formats JPG, PNG, WEBP
  • Output format Same as input
  • Max file size 20 MB
  • Max upscale 4× (AI, device-dependent)
  • Longest side supported Up to 4000 px
  • Max output size ~32 MP desktop, ~16 MP on iPhone/iPad
  • Processing location Your browser, on-device

When you choose 2× or 4×, QualityUpgr tries to run a real local AI super-resolution model (ESRGAN-Slim, via TensorFlow.js) directly in your browser — it reconstructs plausible detail rather than just stretching pixels. Only the model for the factor you picked is downloaded. It first tries your GPU (WebGL); without one it falls back to a slower CPU pass, and skips AI entirely on large images where a CPU pass would take minutes; if AI can't run at all, you get high-quality stepped resampling instead — never a silent trick. Whichever engine actually ran is labeled under your result.

Either way, the photo is measured first — sharpness, noise, contrast and compression artefacts — and the amount of sharpening is chosen from those measurements. A photo that's already sharp gets almost none. Sharpening only touches brightness, never colour, and is limited so it can't ring or halo around edges. Before the result is shown, it's checked against the original for brightness, colour and clipping; if anything drifted, the pipeline pulls back rather than handing you a damaged image. At 1× nothing is resized — you get that same adaptive enhancement at the original dimensions.

Your files stay under your control.

Your final enhancement is still performed in your browser. If AI diagnosis is enabled, QualityUpgr sends a reduced preview of your photo to Groq for analysis so it can identify the main quality problems and choose a safer processing plan. The original full-resolution file is not sent to Groq.

The Groq API key is kept server-side in Vercel and is never exposed in this page's JavaScript.

Closing or reloading the tab clears everything — nothing is kept after your session.
